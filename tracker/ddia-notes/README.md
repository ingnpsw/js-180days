# DDIA Daily Notes

ใช้โฟลเดอร์นี้สำหรับสรุปการอ่าน `Designing Data-Intensive Applications` รายวัน แล้ว commit/push ขึ้น GitHub

## รูปแบบไฟล์
- 1 วัน = 1 ไฟล์
- ชื่อไฟล์: `day-XXX-pages-YYY-ZZZ.md`
- ตัวอย่าง: `day-005-pages-013-015.md`

## เทมเพลต
คัดลอกจาก `TEMPLATE.md`

## ขั้นตอนแนะนำต่อวัน
1. อ่านตามช่วงหน้าจาก tracker
2. สร้างไฟล์ใหม่จากเทมเพลต
3. เขียนสรุปให้ครบ 6 ช่อง
4. commit + push

ตัวอย่างคำสั่ง:

```bash
git add tracker/ddia-notes/day-005-pages-013-015.md
git commit -m "docs(ddia): day 5 notes pages 13-15"
git push
```
