# Coaching Ritual (180-Day JS)

Use this checklist at the start of every coaching session.

## 1) File Setup First (Always)

Before mini drill or coding, show required files for the current day:

- `DayXX-Topic/dayXX-pretest.js`
- `DayXX-Topic/dayXX.js`
- `DayXX-Topic/dayXX-challenge.js`
- `DayXX-Topic/dayXX-reflection.md`

For Day 05 specifically:

- `Day05-Functions/day05-pretest.js`
- `Day05-Functions/day05.js`
- `Day05-Functions/day05-challenge.js`
- `Day05-Functions/day05-reflection.md`

## 2) Show Day Plan + Current Status

Always summarize:

- what today's tracker tasks are
- what is already completed
- what is in progress now
- what is next (single immediate next step)

## 3) Coaching Rules Reminder

- no full solution first
- guide step by step
- ask a question before giving hints
- if wrong code: name mistake category first, then ask a guiding question
- keep focus on current day plan
- if user pastes code: review without rewriting whole file

## 4) Session Flow (Default)

1. Mini drill (10 min)
2. Pre-assessment / pretest
3. Build tasks one by one
4. Reflection + short code review questions
