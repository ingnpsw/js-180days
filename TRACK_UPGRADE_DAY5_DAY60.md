# Day 5-60 Upgrade Plan (React + TypeScript Job Track)

This upgrade plan extends the existing 180-day routine to target Frontend roles using React and TypeScript.

## Target Outcome by Day 60

- Strong JavaScript fundamentals and problem-solving consistency
- React + TypeScript project experience (real portfolio quality)
- Better interview readiness (technical + English communication)
- Application-ready package: CV, LinkedIn, GitHub project documentation

## Daily Format (Keep Existing Tracker Flow)

1. Mini drill (10 min)
2. Pre-assessment/pretest (15 min)
3. Learn (15 min)
4. Build (45 min)
5. Challenge (20-30 min)
6. Reflection + code review questions (10 min)

## Phase Plan

### Phase 1: Day 5-14 (JS Core)

Focus:

- functions, arrays, objects, scope, and repeated logic
- pattern and formula thinking
- cleaner naming and readable code

Deliverable:

- solve daily logic tasks with less hint dependency

### Phase 2: Day 15-30 (DOM + Async + API)

Focus:

- DOM events and form handling
- localStorage
- Promise, async/await, fetch, and error handling
- loading/empty/error UI states

Deliverable:

- mini CRUD-style app with API integration

### Phase 3: Day 31-45 (React + TypeScript)

Focus:

- component architecture and state flow
- TypeScript basics: type, interface, union, generic (beginner-safe)
- typed props/state/events/API responses

Deliverable:

- React + TypeScript dashboard mini app

### Phase 4: Day 46-60 (Production Mindset)

Focus:

- performance basics (memoization, lazy loading, bundle awareness)
- testing basics (Vitest + React Testing Library)
- accessibility basics (semantic HTML, keyboard flow, ARIA)
- project polish and interview preparation

Deliverable:

- portfolio-ready project with tests, accessibility checks, and deployment

## Portfolio Requirements by Day 60

- Project 1: React TypeScript dashboard
- Project 2: booking/e-commerce style flow
- Project 3: fintech-style transaction interface (filters/search/table/chart)

Each project should include:

- live demo
- repository with clean README
- key features list
- technical decisions and trade-offs

## Weekly KPI

- 6 active study days + 1 review day
- minimum 5 meaningful Git commits/week
- 1 completed mini feature/week
- 1 mock interview/week (English or mixed Thai-English)

## Job Readiness Checklist

- CV in English (one-page focused version)
- LinkedIn profile aligned with frontend target
- GitHub profile pinned with the top 3 projects
- answer bank for common frontend interview questions

## Coaching Start Ritual (Always)

Before coding each day:

- show required files for that day
- show day plan and current status
- confirm immediate next step only
